# ninfer engine

[ninfer](https://github.com/Neroued/ninfer), for the RTX 5090 and the RTX PRO 6000 Blackwell.

## Good to know

* RTX 5090 or RTX PRO 6000 Blackwell on x86_64 Linux only. Both use the same chip; the RTX PRO 6000
  has not run ninfer on a real card yet.
* The first deployment may build the engine on the machine, which takes about 3 to 9 minutes.
