# Development tooling

`dev/` holds what runs Dotcore from source on your machine. Each checkout gets its own environment, a local stack with the backend, the console and the web server in front of them, and a development site, which can use simulated models and apps. Tools here also run commands on remote machines with hardware you lack, and spread a development site over several machines.

[Developing Dotcore](../docs/development/README.md) explains how to use it.
