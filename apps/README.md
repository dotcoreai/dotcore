# Applications

The apps Dotcore can run next to your models. Each one runs in Docker, on Linux and on macOS.

| App                       | What it's for                                  | Login                       |
| ------------------------- | ---------------------------------------------- | --------------------------- |
| [Open WebUI](open-webui/) | Chat with your models                          | None                        |
| [ComfyUI](comfyui/)       | Generate images and video from workflows       | None                        |
| [Hermes](hermes/)         | An AI agent with tools, memory and a dashboard | None                        |
| [n8n](n8n/)               | Automate workflows that call your models       | Fixed, shown in the console |

Deploy them from the console. Each folder's README says how to use the app and what to watch for.

Maintaining the images: [`AGENTS.md`](AGENTS.md).
